## Как устроены страницы этого сайта — копируем паттерн /services

Новая страница = `app/gde-poest/page.tsx` + `app/gde-poest/gde-poest.css`.

Обязательные части, по образцу `app/services/`:
1. **HeaderMode** — клиентский компонент, регистрирует режим шапки.
   Скопировать `app/services/ServicesHeaderMode.tsx`, переименовать ключ
   (`register('gde-poest-page', { mode: 'dark', priority: 20 })`).
   Нужен, потому что страница светлая и тёмный текст шапки обязателен.
2. **Reveal** — анимация появления блоков по скроллу.
   Скопировать `app/services/ServicesReveal.tsx`, сменить префикс класса.
   ВАЖНО, прочитать комментарий внутри: `opacity:0` не должен стоять в вёрстке,
   класс-пряталку вешает сам скрипт. Иначе робот без JS видит пустую страницу.
   Плюс это ломает страницу для гостя с отключённым JS — а у нас страница-утилита.
3. **Footer** — `@/components/Footer`, как на /services.
4. **JsonLd** — `@/components/JsonLd`, разметка из `spec/gde-poest/seo.md` раздел 4.
5. `import './gde-poest.css';`

## Иконки: НЕ рисуем новые, берём готовые

В `app/services/icons.tsx` уже есть библиотека инлайн-SVG (viewBox 0 0 32 32,
stroke="currentColor", strokeWidth 1.5, aria-hidden="true"). Готовые и подходящие:
- `IconCoffee` — для «Эндорфина»
- `IconStore` — для супермаркета «Яблоко»
- `IconBreakfast` — для блока завтрака
- `IconPhone` — для телефонов и доставки
- `IconArrowRight`, `IconArrowDown` — для кнопок
- `IconInfo` — для пояснений

Чего не хватает и что нарисовать в том же стиле (viewBox 32x32, stroke 1.5, currentColor):
- иконка метки на карте (для кнопок «Открыть на карте»)
- иконка столовых приборов / ресторана (для блока кафе)
Положить их в `app/gde-poest/icons.tsx`, импортируя недостающее из `../services/icons`.
ЭМОДЗИ ЗАПРЕЩЕНЫ. Все эмодзи из исходного текста менеджера заменяются иконками.

## Мобайл-фёрст — это не пожелание, а основной сценарий

Ссылку открывают с телефона из Telegram/WhatsApp. Проектируем от 360px.
Все телефоны — `tel:`, все карты — внешние ссылки, тач-таргеты не меньше 44x44px.
Внешние ссылки: `target="_blank" rel="nofollow noopener"`.

## Правки оркестратора к copy.md (приоритет выше, чем copy.md)

1. **Название кофейни на странице — «Эндорфин», а не «Endorphinsense Coffee».**
   Гость ищет глазами вывеску и карточку на Яндекс.Картах, а там он значится как
   «Эндорфин». Латинское написание ENDORPHINSENSE COFFEE оставляем мелкой строкой-
   вордмарком под названием — это красиво и честно, но навигирует гостя именно
   кириллическое имя. Заголовок карточки: Эндорфин.

2. **Закрывающая подпись — вариант А.** «Приятного аппетита. Если понадобится
   помощь — мы на ресепшне. / Команда апарт-отеля „Стиль Жизни“». Короче, и в нём
   есть конкретное действие.

3. **Кнопки WhatsApp/Telegram в блоке завтрака НЕ ДЕЛАЕМ.** Мы не знаем, заведён ли
   на номере +7 978 503 63 63 WhatsApp. Кнопка, ведущая в пустоту, хуже её отсутствия.
   Оставляем два телефона. Когда менеджер подтвердит канал — добавим.

4. **Кнопка «Посмотреть меню» в карточке «Эндорфина» — не выводится вовсе** (не
   disabled, а просто нет в разметке), пока нет ссылки. Как и предложено в copy.md.
