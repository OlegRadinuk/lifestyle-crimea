# Расширения объявлений — заполнить в кабинете Директа

Зачем: объявление без расширений — одна строка, с расширениями — три-четыре,
плюс телефон и ссылки. Это бесплатно и обычно даёт заметный рост CTR при той же
ставке. У конкурентов в выдаче («Суточно.ру», pelican-alushta.ru) они есть,
у нас — нет.

Через API прикрепить не вышло: кабинет `lifestylecrimeals` отдаёт ошибку 58
(приложение не сертифицировано для API v5). Поэтому — руками, разово.

Все лимиты ниже — жёсткие ограничения Яндекса, тексты уже под них подогнаны.

## Порядок в интерфейсе

Кампания → группа → объявление → «Редактировать» → блок «Дополнения».
Быстрые ссылки и визитку удобнее завести один раз в библиотеке
(«Библиотека» → «Быстрые ссылки» / «Визитки») и потом выбирать из списка,
а не набивать в каждом объявлении заново.

После правки объявления уходят на модерацию повторно — это нормально,
показы при этом не останавливаются, крутится прошлая версия.
